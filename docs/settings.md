# Settings

Open settings from the right-click context menu on the menu bar icon, or from the popover.

<!-- TODO: Add screenshot of the settings window -->

## Durations

| Setting | Range | Default |
|---|---|---|
| Work duration | 1-60 min | 25 min |
| Break duration | 1-30 min | 5 min |

## Behavior

| Setting | Default |
|---|---|
| Auto-start next session | Off |
| Play sounds | On |
| Show time in menu bar | On |
| Check for updates automatically | On |

## Completion alerts

Choose how you are notified when a session ends:

| Style | Description |
|---|---|
| Pill | Compact horizontal bar near the menu bar |
| Centered | Large dialog in the center of the screen |
| Corner | Small card in the bottom-right corner |
| None | No visual alert (system notification only) |

Alerts auto-dismiss after 10 seconds when auto-start is enabled.

## Activity nudge

Pomodorni can detect keyboard and mouse activity and nudge you when you should be on a break or haven't started a session.

| Setting | Range | Default |
|---|---|---|
| Enable nudge reminders | On / Off | On |
| Nudge delay | 1-30 min | 1 min |

Nudge actions: **Start session**, **Snooze** (5 min), or **Silence until next session**.

## Appearance

| Theme | Description |
|---|---|
| Minimal | Clean, monospaced, indigo accent |
| Glassmorphic | Glass material with gradient overlays |
| Bold | Vibrant gradients, large type, thick progress ring |

## Sounds

| Event | Sound |
|---|---|
| Work session complete | Glass |
| Break complete | Breeze |

Sounds can be disabled globally via the "Play sounds" toggle.
