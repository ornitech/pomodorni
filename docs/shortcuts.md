# Keyboard shortcuts

Pomodorni registers global keyboard shortcuts so you can control your timer without switching windows.

| Shortcut | Action |
|---|---|
| Ctrl+Option+P | Start / Pause |
| Ctrl+Option+S | Skip session |
| Ctrl+Option+R | Reset / Cancel |

These shortcuts work from any app. They are registered via Carbon Events and are always active while Pomodorni is running.
